Import Pengguna CSV

Import hanya membuat pengguna baru. Seluruh file dibatalkan jika ada data tidak valid.

Maksimal 25 pengguna / 1 MiB. Gunakan UTF-8 dengan pemisah koma atau titik koma.

Kolom role pada CSV berarti Jabatan. Isi dengan KEPALA, ADMIN_UMUM, GUDANG, AUDITOR, atau PUSKESMAS. Gunakan true atau false untuk is_active.

Setiap pengguna memakai akses bawaan jabatannya. Password awal wajib diisi; pengguna dapat menggantinya sendiri tanpa kewajiban ganti saat login pertama.

Kolom facility_code pada CSV diisi dengan kode Puskesmas aktif. Untuk pengguna Instalasi Farmasi/non-Puskesmas, biarkan kolom ini kosong; jangan isi nama Instalasi Farmasi, kode gudang, atau tanda "-".

Khusus jabatan PUSKESMAS, facility_code wajib diisi. Untuk ADMIN_UMUM/GUDANG, kolom ini boleh diisi kode Puskesmas aktif hanya jika pengguna memerlukan tautan fasilitas untuk delegasi Puskesmas/LPLPO. Untuk KEPALA/AUDITOR, kolom ini harus kosong.

NIP harus disimpan sebagai teks agar nol di depan tidak hilang.
