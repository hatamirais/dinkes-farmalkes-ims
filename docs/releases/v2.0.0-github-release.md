# v2.0.0

This major presentation release completes the Bootstrap CSS → Tailwind implementation across desktop, authentication/error, mobile and print surfaces. The full release history, including operational UI improvements and security updates since 1.35.0, is in [CHANGELOG.md](../../CHANGELOG.md).

## Presentation and compatibility

- All IMS surfaces use the committed generated Tailwind stylesheet and project-owned components; bound Django fields replace Crispy rendering.
- Removed Bootstrap CSS, legacy desktop/mobile stylesheets, Tom Select's Bootstrap theme, Crispy packages/settings/helpers, duplicate legacy base and the unreachable manual receiving-plan template.
- Custom templates/styles referencing those dependencies must be adapted. `base.html` remains an alias to `base_tailwind.html`.
- Bootstrap JavaScript/state styles and hooks, Bootstrap Icons, Flatpickr and native Django Admin styling remain. This release does not introduce Alpine.js or replace the server-rendered Django architecture.

## Deployment

Install the release's Python requirements and follow the existing migration/static-collection deployment procedure. Compiled Tailwind CSS is committed; Bun/Node are development and CI tools, not production startup dependencies. This documentation/version closeout itself adds no schema migrations or workflow changes.

## Verification and known limitations

The [migration closeout](../css-refactoring/MIGRATION_CLOSEOUT.md) maps the original completion requirements to recorded app, browser, build and static evidence. Native PWA installation/device acceptance and [installation-prompt issue #309](https://github.com/hatamirais/dinkes-farmalkes-ims/issues/309) remain pending. Physical-printer and untested browser/device differences are not claimed verified. The CSS implementation is complete; the original device acceptance gate remains qualified.
